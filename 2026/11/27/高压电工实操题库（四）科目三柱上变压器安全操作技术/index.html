一、030102-K32-01：10kV 柱上 2#变压器跌落式熔断器故障处理

1. 试题要求与考试说明

  • 1. 试题编码：030102-K32-01
  • 2. 试题题目：高压电工作业-10/0.4kV 变配电系统（架空线路）－10kV 柱上 2#变压器跌落式熔断器故障处理
  • 3. 考试任务：2 人一组完成 10kV 柱上 2#变压器跌落式熔断器单相载熔件跌落（熔断件熔体熔断）故障处理（本任务已正确办理工作票或结票）。
  • 4. 考试时间：35 分钟
  • 5. 试题分值：100 分，80 分及以上合格。
  • 6. 考试说明：
    1. 2 名考生组成一个班组，在规定时间内互相配合完成考试任务，抽签确定操作人、监护人。完善操作票时，操作人填写操作票，监护人检查操作票，2 人共同确认操作票（允许修改 1 次操作票），签字后提交。
    2. 考核内容分为个人评分项目和班组评分项目。在个人评分的项目中，当考生“安全不合格项”未通过时，仅“安全不合格项”未通过的考生终止考试，本次实操考试成绩计 0 分；当考生出现扣分情况时，根据情况扣减相应考生分数。在班组评分项目中，当任意一名考生“安全不合格项”未通过时，该班组考生终止考试，本次实操考试成绩计 0 分；当班组内任意一名考生出现“扣分”情况时，同时扣减该班组考生分数。
    3. 在考试过程中，当任意一名考生扣分超过 20 分或“安全不合格项”未通过时，该组考生终止考试，扣分超过 20 分或“安全不合格项”未通过的考生，本次实操考试成绩计 0 分；扣分未超过 20 分或未涉及“安全不合格项”未通过的考生，重新分组后重新执行考试任务。
    4. 超时未完成全部考核内容的，根据完成项目计分，如未完成部分有“安全不合格项”的，本次实操考试成绩计 0 分。
    5. 未作答本题的，本次实操考试成绩计 0 分。
    6. 考试过程中出现人身伤害情况的，该组考生终止考试，本次实操考试成绩计 0 分。
  • 7. 分值权重：40%
  • 8. 评分标准：见下表

1. 唱票：监护人应按操作项目顺序清晰、准确朗读操作项目内容。如监护人唱票错误，操作人不得复诵，应当场告知监护人“你唱票内容和操作票不符，请重新核对”。核对后重新“唱票”。
2. 复诵：操作人利用手势指出相应设备，清晰、准确复诵操作项目内容。操作人手指设备错误或复诵错误，监护人不得下达许可指令，应当场告知操作人“你手指设备或复诵内容和操作票不符，请和我一同核对操作项目内容”。核对后重新“唱票－复诵”。
3. 确认：监护人目视操作人手指设备、确认复诵内容无误后，下达许可指令“对，执行”。监护人下达的许可指令错误或不规范，操作人停止操作，当场告知监护人“你的指令错误或不规范，请纠正”。纠正后重新下达许可指令。
4. 执行：操作人规范执行操作，监护人确认操作到位且无异常后，在操作项目后方打“√”。操作人执行错误，监护人应立即叫停作业，如操作人未实施实质性误操作或违章操作，应重新执行“唱票－复诵－确认－执行”流程；如操作人已发生实质性误操作或违章操作，监护人应立即报告事故内容，得到“继续”指令后，应重新执行“唱票－复诵－确认－执行”流程。		 操作票中操作项目与考核要点对应的步骤，在执行“唱票－复诵－确认－执行”过程中对监护人、操作人进行独立评分，对执行过程出错承担责任的人员，按考核要点对应“分值”扣分或“安全不合格项”未通过，责任划分规则及特殊情况认定“安全不合格项”未通过情形如下：
1. 唱票：（1）监护人唱票内容错误，如操作人未当场告知，则操作人、监护人同时担责；如操作人当场告知，仅监护人担责。（2）监护人唱票内容正确，如操作人当场告知错误，仅操作人担责。（3）对于仅扣分的操作项目，如监护人连续唱票错误 2 次，认定监护人“安全不合格项”未通过。
2. 复诵：（1）操作人手指设备错误或复诵内容错误，如监护人未当场告知，则操作人、监护人同时担责；如监护人当场告知，仅操作人担责。（2）操作人手指设备及复诵内容均正确，如监护人当场告知错误，仅监护人担责。（3）对于仅扣分的操作项目，如操作人连续复诵错误 2 次，认定操作人“安全不合格项”未通过。

3. 确认：监护人目视操作人手指设备、确认复诵内容无误后，下达许可指令“对，执行”。监护人下达的许可指令错误或不规范，操作人停止操作，当场告知监护人“你的指令错误或不规范，请纠正”。纠正后重新下达许可指令。
4. 执行：操作人规范执行操作，监护人确认操作到位且无异常后，在操作项目后方打“√”。操作人执行错误，监护人应立即叫停作业，如操作人未实施实质性误操作或违章操作，应重新执行“唱票－复诵－确认－执行”流程；如操作人已发生实质性误操作或违章操作，监护人应立即报告事故内容，得到“继续”指令后，应重新执行“唱票－复诵－确认－执行”流程。		 操作票中操作项目与考核要点对应的步骤，在执行“唱票－复诵－确认－执行”过程中对监护人、操作人进行独立评分，对执行过程出错承担责任的人员，按考核要点对应“分值”扣分或“安全不合格项”未通过，责任划分规则及特殊情况认定“安全不合格项”未通过情形如下：

2. 复诵：（1）操作人手指设备错误或复诵内容错误，如监护人未当场告知，则操作人、监护人同时担责；如监护人当场告知，仅操作人担责。（2）操作人手指设备及复诵内容均正确，如监护人当场告知错误，仅监护人担责。（3）对于仅扣分的操作项目，如操作人连续复诵错误 2 次，认定操作人“安全不合格项”未通过。

2. 柱上变压器考位三大高危保命铁律

  1. 防护眼镜 2 副必选必戴：与开关柜（K31）不同，柱上变（K32）拉合跌落式熔断器必须佩戴绝缘手套 1 副 + 绝缘靴 2 双 + 防护眼镜 2 副，漏选或操作中未戴直接全组 0 分！
  2. 跌落式熔断器三相拉合顺序：
    • 拉开（停电）：先中间相 → 后下风侧边相 → 最后上风侧边相；
    • 合上（送电）：先上风侧边相 → 后下风侧边相 → 最后中间相。
  3. 调档口诀与直阻判据（K32-02）：
    • 分接开关 1档(10500V) / 2档(10000V) / 3档(9500V)：“高往高调，低往低调”（低压电压不足往低调至 3 档 9500V）。
    • 高压侧三相线间直流电阻不平衡率：
      $$\text{不平衡率} = \frac{\text{最大值} - \text{最小值}}{\text{三相平均值}} \times 100% \le 2%$$
