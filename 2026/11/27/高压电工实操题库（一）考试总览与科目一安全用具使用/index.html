一、实操考试试卷及考试要求说明

  1. 实操考试试卷包括 4 个科目，分别为科目一安全用具使用、科目二作业现场安全隐患排除、科目三安全操作技术、科目四作业现场应急处置，每个科目设置 1 道试题（按照统一组卷规则在实操考试题库中随机抽取），每个科目试题的合格标准按照试题规定的试题分值、考试说明要求执行。
  2. 实操考试采取考生现场实际操作方式进行考评。
  3. 实操考试时，科目一安全用具使用、科目二作业现场安全隐患排除、科目三安全操作技术必须按顺序进行，未按顺序考试的，本次实操考试成绩计 0 分。
  4. 实操考试时，任意科目试题未作答的，本次实操考试成绩计 0 分。

二、030102-K11-01：安全工器具与仪器仪表的使用 01

1. 试题要求与考试说明

  • 1. 试题编码：030102-K11-01
  • 2. 试题题目：高压电工作业-电力安全工器具与电工仪器仪表考位-安全工器具与仪器仪表的使用 01
  • 3. 考试任务：
    1. 选择合格的安全帽、工作服、安全带（含围杆带、安全绳）、绝缘鞋、脚扣，并按规范穿戴；按规范进行登杆作业，在指定位置设置防坠落保护。
    2. 选择合格的高压绝缘手套、绝缘靴，并按规范穿戴。
    3. 选择合格的数字式万用表，在仪器仪表测试台按规范测量指定电路电压，记录测量结果；选择合格的兆欧表，在仪器仪表测试台按规范测量指定 10kV 橡塑绝缘电力电缆（假定电缆长度 500m）的绝缘电阻，记录测量结果并判断设备绝缘状态。
    4. 识别禁止、指令、警告、提示等四类电气安全标志。
    5. 整理场地。
  • 4. 考试时间：30 分钟
  • 5. 试题分值：100 分，80 分及以上合格。
  • 6. 考试说明：
    1. 在规定时间内完成考试任务。
    2. 考试过程中扣分超过 20 分或“安全不合格项”未通过的，终止考试，本次实操考试成绩计 0 分。
    3. 超时未完成全部考核内容的，根据完成项目计分，如未完成部分有“安全不合格项”的，本次实操考试成绩计 0 分。
    4. 未作答本题的，本次实操考试成绩计 0 分。
    5. 考试过程中出现人身伤害情况的，终止考试，本次实操考试成绩计 0 分。
