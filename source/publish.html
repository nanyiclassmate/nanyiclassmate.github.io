手机日记发布

写完后点发布，博客会自动构建上线。同一天再次发布会更新当天那篇。

GitHub Token 设置（只需填一次）

在手机浏览器打开 github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens，生成后只勾选本仓库的 Contents: Read and write，有效期建议选 90 天以上。Token 只保存在这台设备的浏览器里，不会上传到任何服务器。

标题同时决定文章文件名和网址，建议保持「日期+日记」格式。

图片会插入到文末，正文里也可像平时一样自己写 Markdown。

iPhone 用户：在 Safari 里打开本页，点分享按钮 →「添加到主屏幕」，以后就像 App 一样打开。
